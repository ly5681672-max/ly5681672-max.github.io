# 论文成果自动更新说明

论文页面：<https://ly5681672-max.github.io/publications/>

该站点每周一北京时间约 08:17 通过 GitHub Actions 的 **Sync new publications** 自动检查新论文（GitHub 定时调度可能延迟）。

数据源使用 ORCID 公开 works、OpenAlex 与 Crossref 的出版商 DOI 信息，不直接抓取 ResearchGate 或 Google Scholar 网页。ORCID ID 为 `0009-0004-7005-8512`，只读取公开记录，不需要登录或修改 ORCID 账户。OpenAlex 标识 A5100697597 已命中本站四篇已确认的论文，但该标识也混入部分同名研究者的其他学科成果，**不能单独用于确定作者身份**。脚本同时扫描 Crossref 最近 180 天的新登记或更新记录，再结合作者姓名、机构、已知合作者及 DOI 综合判断。

高置信度入库条件为：Crossref 记录为正式期刊论文，DOI、题名、作者一致，且与 OpenAlex 题名一致。对于 ORCID 公开 works 中明确列出的 DOI，允许没有历史合作者的新论文通过多源 DOI、作者姓名和题名核验；其他来源仍要求 OpenAlex 的作者身份及至少两位已知合作者，或机构与一位合作者匹配。ORCID 记录本身不是最终发表证据。所有不满足入库条件的候选 DOI 都保留在待核验报告中，不自动发布；无法确认的同名记录继续计入排除统计。

符合条件的新论文只追加到 _bibliography/papers.bib，不重写既有论文元数据、TOC 图和精选论文标记。同步更新 _data/publication_stats.yml 总数，并自动触发网站部署。自动更新不负责转载受版权保护的 PDF 或 TOC 原图。

[查看自动检查和审核报告](https://github.com/ly5681672-max/ly5681672-max.github.io/actions/workflows/sync-publications.yml)。每次运行的 publication-monitor-report 附件会列出未入库记录及原因；无需手动上传新论文即可继续定期监测。

也可以在 GitHub Actions 页面使用 Run workflow，选择 dry-run 测试，或选择 apply 立即执行符合条件的入库。只想暂停此功能时，在仓库 Actions 中禁用这个工作流即可。
