# 学术经历页面维护说明

[学术经历页面](https://ly5681672-max.github.io/experiences/) 参考 [Yingjing Huang 的经历展示](https://yingjinghuang.github.io/experiences/) 的 Work / Education / Research Funding 布局。

## 新增经历

1. 在 GitHub 打开 [经历数据文件](../_data/experiences.yml)。
2. 参考 [填写模板](../_experience_templates/经历数据填写模板.yml)，在 `work`、`education` 或 `funding` 对应位置填写真实信息。每次修改只需保存并 Commit。
3. 网站自动部署并更新页面，无需编辑 HTML、CSS 或其他页面。

**注意：** 数据文件中已有的中国石油大学（华东）博士研究生身份，来自网站之前已公开的个人介绍；其他日期、导师、工作经历和科研资助均未填写或推断。

## 可选字段

- 工作和教育：`institution`、`role`、`dates`、`location`、`logo`、`detail`、`links`。
- 同校多个学位：设置 `degrees` 列表，其中每项可写 `name`、`dates`、`detail`、`links`。
- 科研资助：`title`、`dates`、`agency`、`agency_url`、`role`。

**机构徽标：** 把获得使用许可的机构标志上传到 `assets/img/experiences/`，填入 `logo: "/assets/img/experiences/xxx.png"`。没有真实徽标时使用默认学院图标，不会冒用其他学校标志。

排列顺序：每个列表内把最新经历放在最前面；如果没有相应记录，Work 显示待补充信息，Research Funding 先不展示，避免伪造个人履历。
