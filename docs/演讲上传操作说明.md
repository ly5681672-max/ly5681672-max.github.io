# 学术报告上传说明

页面地址：<https://ly5681672-max.github.io/talks/>

参考形式：<https://yingjinghuang.github.io/talks/>

## 每次上传，只需这三步

1. 打开 [演讲上传模板](../_talk_templates/演讲上传模板.md)，复制整份 Markdown。
2. 在 GitHub 仓库的 `_talks/` 中创建一个文件，建议命名为 `YYYY-MM-DD-英文简短标题.md`，粘贴模板并修改顶部字段，然后提交到 `main`。
3. 如果有 PPT、海报或报告 PDF，先上传到 `assets/pdf/talks/`，并把对应路径填入 `materials`。如果只有 Bilibili/YouTube 视频或会议网页，直接填完整网址，不用上传文件。

保存后 GitHub Pages 自动构建，页面会自动按日期从新到旧排序，无需修改 `_pages/talks.md` 或 CSS。

## 字段说明

必填字段为 `title`（演讲标题）、`date`（真实日期，格式 YYYY-MM-DD）、`category`（`invited` 邀请报告、`conference` 会议口头报告或 `poster` 海报）、`venue`（主办单位或会议）、`location`（举办地点或 Online）。

`materials` 为可选附件列表，每项填写 `label`、`url` 和 `type`；没有附件时可以不写该字段。

`materials.type` 建议使用 `video`（视频）、`slides`（PDF/PPT）或 `link`（会议网址）。
PPTX 可以直接放入 `assets/pdf/talks/` 并用 `type: link` 链接，若希望浏览器内预览建议导出 PDF。

### 注意

- 不要直接把模板保存在 `_talks/` 里，否则占位文字会被网站当作正式演讲发布。
- `_talk_templates/` 是可复制的模板目录，不会生成虚构报告。
- `_talks/` 中每一篇 Markdown 都是独立记录，新增、编辑、删除一篇不会改变其它记录。
- 报告日期用于排序；会议报告与 Poster 自动合并到 _Conference Presentations_。
- GitHub 图片/附件上传请注意论文、照片和会议材料的共享权限。
